# UAE 外籍劳工流入代理指标

调研日期：2026-08-13。

## 结论

可以构建月度代理指标，但不能把它解释为 UAE 全部外籍劳工的实际入境人数。菲律宾、尼泊尔、孟加拉国均能在官方数据中单独识别 UAE，且已形成可自动更新的月度序列；三者分别衡量部署、最终劳工批准和出境许可，统计口径并不相同。最合适的用途是观察主要劳务输出国流向 UAE 的方向和拐点，而不是估计 UAE 外籍就业存量或总流入。

巴基斯坦、斯里兰卡和印度可以识别 UAE，但缺少稳定、及时、可连续批量抓取的国家别月度发布，因此暂不纳入月度代理指标。它们更适合年度回溯和交叉验证。

## 处理方法

1. 菲律宾：读取 Tab 11 的 UAE 行，分别提取部署总计、新雇和再雇的 YTD 数值，再按年份内相邻报告差分为月值。2026-02 的官方 YTD 总计从 57,207 回落到 36,772，无法可靠差分；该月菲律宾数值留空并写入质量标记。2025-12 未找到稳定公开 Excel，因此同样留空。
2. 尼泊尔：从 Country Wise 表直接提取 UAE 行的“含再入境”和“不含再入境”最终批准数。报告周期不是严格公历月，按周期结束日所在的公历月归档。
3. 孟加拉国：对 UAE 国家筛选器逐自然月调用 OEP JSON 接口，只保留完整月份。
4. 重点三国合计只在三国当月均有有效值时计算。
5. 等权代理指数先将各国月值除以 2025-05 至 2025-11 共同覆盖期均值，再对三国等权平均并乘以 100。这样可避免菲律宾绝对规模较大而完全支配指标；基期只包含 7 个月，指数应在历史扩展后重定基。

### 仅在处理文件中保留的辅助字段

以下字段不写入 `data/阿联酋.xlsx`，只保留在处理 CSV 中，供数据质量审计和后续研究使用：

- `重点三国等权代理指数_2025重叠期100`：三个国家分别以 2025-05 至 2025-11 共同覆盖期均值标准化，再等权平均；基期均值为 100。
- `官方源覆盖国家数`：当月菲律宾、尼泊尔和孟加拉国三个官方源中具有有效观测的国家数量，范围为 1–3。
- `质量标记`：记录官方累计值回溯等异常。当前菲律宾 2026-02 的 YTD 总计从 57,207 回落到 36,772，因此该月不计算菲律宾月值。

Excel 的 `月度_外籍劳动力` sheet 只保留日期、三国原始官方指标以及 `重点三国合计_可比月`，共 8 列。

## 文件与运行

- `download_data.py`：发现并下载官方原始文件/API 结果，写入本地 `raw/`。
- `process_data.py`：解析、校验、生成 `processed/uae_foreign_labour_monthly.csv`，并更新 `data/阿联酋.xlsx` 的 `月度_外籍劳动力` sheet。
- 原始文件、处理结果、备份和工作簿均受 `.gitignore` 保护；代码和本说明可纳入版本控制。

在仓库根目录运行：

```powershell
.\runtime\python.exe data\foreignEmployer\download_data.py --source all
.\runtime\python.exe data\foreignEmployer\process_data.py
```

若 `data/阿联酋.xlsx` 正在 Excel 中打开，处理脚本不会覆盖它，而会生成带时间戳的 `data/foreignEmployer/阿联酋_with_foreign_labour_*.xlsx`。关闭原工作簿后再次运行第二条命令即可安全写回目标文件。

## 使用限制

- 三个官方源衡量的是输出国行政流程，不是 UAE 入境口岸记录；批准、许可、部署和实际到岗之间存在时滞与撤销。
- 指标只覆盖三个重点输出国，不能外推为 UAE 全国外籍劳工总流入。
- 尼泊尔周期存在约半个月的公历偏移；短期冲击可能被分配到相邻公历月。
- 菲律宾月值依赖 YTD 差分，官方修订或累计值回落会造成缺口。自动处理不会把负差分当成负流入。
- 印度官方数字通常只覆盖需办理 Emigration Clearance 的 ECR 护照劳动者，不代表全部印度赴 UAE 就业者。
