# 数据说明 —— 阿联酋数据源统一 DuckDB 管理

本文档说明 `data/UAE/` 下统一 DuckDB 数据库 `uae.duckdb` 的管理方式：数据来源、表结构、
清洗口径、更新与合并方法、**自动运行配置**、常见问题。十类数据源的原说明已合并于此。

## 1. 总体结构

```text
data/UAE/                  数据区（数据、原始件、文档、自动运行配置）
├── uae.duckdb            统一数据库（唯一数据存储）
├── 阿联酋.xlsx           目标工作簿（仪表盘读取；由合并脚本维护）
├── 工作搜索热度.csv      从库导出的谷歌趋势宽表（仪表盘读取）
├── raw/<源>/             各源原始下载件与缓存（本地，不入 Git）
├── .env                  数据源密钥（如 COMTRADE_API_KEY，本地，不入 Git）
├── auto_update_all.bat   定时自动运行入口（更新+合并一步完成，供任务计划程序）
├── 数据说明.md           本文档
└── README.md             目录速览

data/UAE/scripts/              脚本区（管线脚本统一集中）
├── update_data.py/.bat   总控：抓取 → 清洗 → 入库（双击入口）
├── merge_workbook.py/.bat 总控：库 → 阿联酋.xlsx（双击入口）
├── db.py                 共享 DuckDB 连接 / 建表 / 写入 / 运行日志工具
├── source_<源>.py        每源一个模块：download → parse → load → merge
├── fetch_official_news.py DED 官方数字半自动提取（人工确认后入库）
├── write_*.ps1           Excel COM 写表助手（保留工作簿批注、链接等部件）
└── merge_*.ps1           Excel COM 写表助手（steel/comtrade/dld 通道）
```

`data/` 根目录只保留 UAE 管线（`UAE/` 数据区 + `scripts/` 脚本区）与本管线无关的
既有内容（`工业/`、`暂存/`、`sheet.txt`、`users.db`），不再存放各源散乱目录。

两条独立命令（从仓库根目录执行）：

```powershell
runtime\python.exe data\UAE\scripts\update_data.py      # 1. 更新数据进 uae.duckdb
runtime\python.exe data\UAE\scripts\merge_workbook.py   # 2. 从库合并进 阿联酋.xlsx
```

常用参数：`--source cbuae,gfs`（只处理指定源）、`--skip-download`（不联网，只用
`raw/` 缓存）、`--force`（强制重下缓存输入）。合并脚本另有 `--workbook <路径>`。

- **更新**：某一源失败不影响其他源，结束后打印每源状态；有任何失败退出码为 1。
- **合并**：写入前必须关闭 Excel 中打开的 `阿联酋.xlsx`。各写表通道保留原有
  “备份 → 临时副本 → 写入 → 验证 → 原位替换/回滚”机制。
- 每次更新在 `meta_source_runs` 表留下运行记录（来源、起止时间、状态、说明）。

## 2. 数据库结构（uae.duckdb）

### 2.1 观测表（main schema）

月度表的 `period` 一律为**月末日期**（如 2020-01-31）；缺报月份不存行（合并时留空，
不插值、不前向填充）。

| 表 | 粒度 | 主要字段 |
|---|---|---|
| `baker_hughes_monthly` | 月 | period, oil_rigs（阿联酋石油活跃钻机数，Oil 口径，阿布扎比+迪拜+沙迦合计） |
| `cbuae_monthly` | 月×指标 | period, indicator, value（百万迪拉姆）, source_period, source_file |
| `gfs_quarterly` | 年×季×指标 | year, quarter, indicator, value（百万迪拉姆） |
| `gfs_annual` | 年×指标 | year, indicator, value（年度列直取，不由季度加总） |
| `pmi_monthly` | 月 | period, value, source_label, source_url |
| `foreign_labour_monthly` | 月×序列 | period, series, value, quality_flag |
| `comtrade_monthly` | 月×分类 | period, category, value（美元）, units（台/件） |
| `comtrade_partner_detail` | 月×分类×申报国×伙伴 | period, category, reporter, partner, value |
| `comtrade_quantity_detail` | 月×HS6 | period, hs6, item_count, source_type, reported_estimated, mirror_reporter_count |
| `mesteel_monthly` | 月×产品 | period, product, lower, upper, midpoint（美元/公吨）, origin_label |
| `ded_monthly` | 月×序列 | month, series（records/enterprises/licences/official_new_licenses）, value |
| `ded_monthly_by_type` | 月×法律形式 | month, legal_form, records |
| `employment_search_index` | 月×关键词 | month, keyword（work in dubai / work in uae）, value |
| `dld_investment_pipeline_weekly` | 周 | week_end + 6 个投资落实代理指标 |
| `dld_sales_monthly` | 月×指标 | period（月末）, indicator（4 个销售分市场）, count（笔数）, value_aed（金额，AED 原值） |
| `dld_lease_monthly` | 月×指标 | period, indicator（合同总数/新签%/续签%/住宅%/商业%）, value, source_url |

| `tdra_telecom_monthly` | 月×指标 | period, indicator（9 个电信订阅指标）, value, source_file |
| `cloudflare_radar_daily` | 日×指标 | period, indicator, value（相对水平%, min-max 归一）, source_file |

### 2.2 DLD 明细表（dld schema）

| 对象 | 类型 | 说明 |
|---|---|---|
| `dld.transactions` | 表 | 房地产交易明细，**只保留被周度/月度指标与三个视图消费的列**（`KEEP_COLUMNS`：transaction_id、instance_date、trans_group_en、reg_type_en、project_number、actual_worth、property_type_en、property_usage_en、load_timestamp 共 9 列；约 176 万行。2026-08 瘦身 47→8，同月回补 property_usage_en 至 9 列供月度销售指标分市场） |
| `dld.land_transactions` | 视图 | transactions 中 property_type_en='Land'（按保留列投影） |
| `dld.transaction_year_summary` | 视图 | 年份×交易大类×房产类型×登记类型汇总 |
| `dld.transaction_date_quality_issues` | 视图 | 日期早于 1900 年或无法解析的交易（按保留列投影） |

> 2026-08 瘦身：`dld.land_registry`（仓库内零消费）已不再建表入库；原始 CSV 与
> 旧库仍完整保留在 `raw/dld/`，需要时可单独重建。transaction_id 唯一性由数据源
> 保证、在建表阶段以断言兜底，不再建持久化唯一索引（省约 68MB）。

## 3. 各数据源说明

### 3.1 Baker Hughes 钻机（source_baker_hughes.py）

- 原始文件：`raw/baker_hughes/` 下的 `WorldWide Rig Count Report.xlsx`（手工下载放入）。
- 更新方式：脚本自动选择**观测期最新**的有效文件（不依赖文件名），只汇总
  `DrillFor=Oil` 的阿布扎比、迪拜、沙迦月度活跃钻机数；Gas/Miscellaneous 不计入。
  数据未变化时不重写。
- 目标 sheet：`月度_贝克休斯`（指标：阿联酋石油活跃钻机数，单位：台）。

### 3.2 阿联酋央行统计公报（source_cbuae.py）

- 原始文件：`raw/cbuae/` 下 `YYYY-MM.xlsx` / `YYYY-MM.pdf`（每月从央行官网下载放入）。
- 清洗口径：从全部银行国内信贷与居民/非居民存款表提取政府与政府控股企业
  4 条序列；同一观测月多个公报版本时**最新公报优先**；公报缺失月份用工作簿
  `月度_Wind` 中对应 Wind 序列回填（Wind 只补缺、不覆盖央行数据）。数值单位百万迪拉姆。
- 目标 sheet：`月度_CBUAE`（数据行固定按月从晚到早）。

### 3.3 财政部 GFS（source_gfs.py）

- 原始文件：`raw/gfs/` 下 `GFS-YYYY.pdf`（2012–2023）与 `GFS-YYYY.xlsx`（2024 起）。
- 清洗口径：29 个 GFS 指标（收入、费用、营业余额、非金融资产净投资、净贷款/借款、
  金融资产与负债等）；**年度值直接采用原件年度列，不由季度数相加**（原件明确说明
  两者不一定相等）。写入后逐单元格校验，报告写入 `raw/gfs/validation_report.json`。
- 目标 sheet：`季度_GFS`、`年度_GFS`、`指标字典`（GFS 部分）。
- **手动抓取新闻稿**用 `data/UAE/scripts/fetch_official_news.py`（DED 官方数字，见 3.7）。

### 3.4 UAE PMI（source_pmi.py）

- 数据源：S&P Global 编制；抓取入口为 Trading Economics 公开展示页
  （<https://tradingeconomics.com/united-arab-emirates/manufacturing-pmi>），
  仅含经授权的有限 headline 样本，**不是完整调查历史**。
- 目标 sheet：`月度_LSEG`（单元格“来源”如实写 `S&P Global / Trading Economics（公开样本）`）。
- 质量报告：`raw/pmi/quality_report.json`（历史覆盖、连续性、重复值、取值范围、最新性）。

### 3.5 UN Comtrade 资本品进口（source_comtrade.py）

- 原始文件：`raw/comtrade/` 下直报与镜像 JSON 缓存；口径文件在
  `raw/comtrade/reference/commodity_scope.csv`（59 个 HS6 码，五类：制造设备、
  土建施工设备、大型能源项目设备、钻探设备、港口及铁路设备）。
- **来源优先级（每月每类独立选择）**：1) 阿联酋直报有值→只用直报；2) 否则汇总
  全体申报国对阿出口（镜像）；3) 都无→留空。不做滚动平均/滚动求和。
  台数按同样优先级逐 HS6 选择。直报按 CIF、镜像按 FOB，来源切换存在口径断点。
- API 密钥：`data/UAE/.env` 中的 `COMTRADE_API_KEY`（本地文件，不入 Git）。
- 目标 sheet：`月度_UNComtrade`。

### 3.6 MEsteel 钢材价格（source_steel.py）

- 数据源：<https://mesteel.com/newsletter/monthly_prices_latest4.php>，CFR/CPT UAE，
  美元/公吨；接口月初日期转换为月末日期；工作簿值为报价区间中值 `(下限+上限)/2`。
- 清洗口径：产品产地标签变化会拆成若干段，脚本按产品合并；若未来同产品同月出现
  多条报价，脚本**停止并报错**，避免静默覆盖。缺报月份留空。
- 目标 sheet：`月度_MEsteel`。

### 3.7 DED 迪拜企业注册（source_ded.py）

- 原始文件：`raw/ded/DED_data/raw/` 快照（data.dubai Commerce Registry，数据集 460521，
  每月更新，gzip 约 58MB）。
- 清洗口径（按发照月去重）：当月有发证活动的企业数 = `commerce_number` 按发照月去重
  （剔除占位 `'0'`）；当月新发执照数 = `main_license_number` 按发照月去重。
  经逐月核对（2012–2026 样本），快照中企业号↔月份一一对应，「企业号首现筛重」
  数值恰好等于「当月有发证活动的企业数」，故正名不改数。
  **存量快照非流量**：已注销企业不在库中，越早年份越低估（2020 约 36%、2021 约
  56%、2022H1 约 72%、近期 70%+）；17.7% 无发照日期记录无法归月已排除；
  覆盖迪拜 DED 系统，不含自由区执照。
- 官方数字：人工维护 `raw/ded/official_ded_monthly.csv`（month, official_new_licenses,
  note, source_url）；半自动抓取新闻稿用 `data/UAE/scripts/fetch_official_news.py`
  （官方数字维护、fetch_official_news 流程、快照筛重原理与参数详见
  **`数据说明_DED.md`**）。
- 目标 sheet：`月度_DED`（当月有发证活动的企业数/当月新发执照数（按发照月去重）+ 官方新发执照数三列）。

### 3.8 DLD 迪拜房地产（source_dld.py）

- 原始文件：`raw/dld/` 下三个全量 CSV（DLD_Transactions_ALL.csv 约 1GB）、清单
  JSON、旧版 `DLD.duckdb`（首次整合时由旧库迁移，避免重下重导），以及
  `moasher_page_urls.txt` / `moasher/*.html`（Mo'asher 月度页清单与缓存）。
- 数据源：Data Dubai — Real Estate Transactions / Land Registry
  （<https://data.dubai/en/l/470061> 与 <https://data.dubai/en/l/465348>）。
  现使用官方 bulk 数据集；租赁合同指标来自 DLD Mo'asher「Official Rental
  Performance Index」月度报告（Property Finder Insights Hub 镜像，
  <https://www.propertyfinder.ae/en/insightshub/moasher/>）。
- 下载策略：全量 CSV 仅在建库缺失或 `--force` 时重下（约 1GB，数分钟）；平时
  更新只用本地库计算周度/月度指标。
- 入库裁剪（2026-08 瘦身）：`dld.transactions` 只保留被周度/月度指标与三个视图
  消费的 9 列（`KEEP_COLUMNS`，47→9）；`dld.land_registry` 仓库内零消费，不再
  建表。原始数据仍完整下载到 `raw/dld/`，可随时按需重建全量。
- 周度指标：项目启动指数、期房销售吸收指数、项目商业转化指数等 6 个代理指标，
  由 dld.transactions 计算（方法详见 `raw/dld/` 清单）。目标 sheet：`周度_迪拜房地产`。
- **月度销售指标（2026-08 新增）**：`dld_sales_monthly` 按月聚合
  Sales ×（Off-Plan 期房 / Existing 现房）×（Residential 住宅 / Commercial 商业）
  的笔数与金额（AED 原值入库，写表折算百万 AED），2009 起全历史、本地精确。
  ⚠️ DLD 的 Existing 口径混含一手现房与二手房，且无买卖双方身份字段，**无法拆分
  一手/二手**；期房/现房才是官方边界。
- **月度租赁合同指标（2026-08 新增）**：`dld_lease_monthly` 按 Mo'asher 官方
  边缘口径入库：租赁合同总数、新签占比、续签占比、住宅占比、商业占比（%）。
  ⚠️ 官方只发布边缘分布（总数 + 各占比），**从不发布「住宅×新签」等交叉绝对数**，
  故按可得口径入库，不估算交叉值；目前可覆盖 2022-01 ~ 2024-12（该镜像期；更早/
  更晚月份官方未发布月度租赁指数，留空不插值）。
- 目标 sheet：`周度_迪拜房地产`、`月度_DLD`（14 列：日期 + 8 销售列[4 分市场×
  笔数/金额] + 5 合同列；按月降序）。

### 3.9 外籍劳工流入（source_foreign_labour.py）

- 数据源（三国官方）：菲律宾 DMW Monthly Compendium（Tab 11 累计部署，相邻月差分）、
  尼泊尔 DoFE 月度劳工批准（PDF，周期约跨公历月中，按周期结束日归档）、孟加拉国
  BMET/OEP 国家筛选 JSON（逐自然月，只保留完整月）。
- 口径限制：三个源衡量的是**输出国行政流程**（部署/批准/出境许可），不是 UAE 入境
  记录；只覆盖三个重点输出国，不能外推为 UAE 全部外籍劳工流入；菲律宾 2026-02
  YTD 回落导致该月留空并写质量标记；重点三国合计只在三国当月均有有效值时计算；
  等权代理指数（2025 重叠期=100）等辅助字段只入库、不写工作簿。
- 目标 sheet：`月度_外籍劳动力`（日期 + 三国原始官方指标 + 重点三国合计_可比月，共 8 列）。

### 3.10 工作搜索热度（source_employment.py）

- 原始文件：`raw/employment/工作搜索热度.csv`（谷歌趋势月度导出，手工放入）。
- 无下载器、无目标 sheet：入库后由合并脚本导出 `data/UAE/工作搜索热度.csv`
  （列名 Time / work in dubai / work in uae），供仪表盘政府财政页双轴图读取。

### 3.11 UAEWPS 工资保护系统统计（source_uaewps.py）

- **官方入口**：CBUAE 官网「Payments and Settlements → Monthly Statistics →
  UAE Wages Protection System (UAEWPS) Statistics」列为月度统计发布，但该入口
  当前为**空占位**（列表项无文件链接；经真实浏览器渲染、站点地图、出版物 API
  `MediaListing/Get`、OpenData 表面线索与 Wayback 存档逐一核验，无任何可下载
  月度文件）；CBUAE 月度统计公报亦不含 UAEWPS 表。
- **实际数据来源**：CBUAE 季度经济评论（QER）「Employment and Wages」小节，
  每期公布截至**季末月**的 WPS 覆盖员工数与平均工资**同比增速（3 个月移动
  平均口径，见 QER 脚注）**。原始文件 `raw/uaewps/qer/20XXQY.pdf`（18 期，
  2021Q4 至 2026Q2，人工从 CBUAE 官网下载）解析出 2024Q1 起 9 期、合计 9 个
  月度观测点（2024-04 → 2026-03）。
- 指标（单位同比%，长表 `uaewps_monthly`）：
  `阿联酋:WPS覆盖员工数同比%(3个月移动平均)`、`阿联酋:WPS平均工资同比%(3个月移动平均)`；
  2024-06 员工数官方表述为"几乎持平"未给增速，该值以 `None` 入库、Excel 留空。
  **频率为「季」**：每期 QER 一个观察点，period 记为季末月。
- **防漂移校验**：解析结果与 `source_uaewps.py` 中 `EXPECTED` 校验表逐期核对，
  不一致即拒绝入库；新一期 QER 需人工核对后加入校验表再更新。
- 目标 sheet：`季度_UAEWPS`（早期版本曾写入 `月度_UAEWPS`，合并时自动删除）。
- 数据来源：IMF PortWatch 日度海运数据（HDX 每日镜像，原始 CSV 缓存于
  `raw/portwatch/`）；`portwatch_uae_daily`（UAE 15 港口，2019-01-01 至今，
  逐日 7 类到港次数与 7 类进口/7 类出口吨位）、`portwatch_chokepoint_daily`
  （28 个海峡，2019-01-01 至今，逐日 7 类过境次数与 7 类载货容量）。海峡侧
  **Excel 只取霍尔木兹**（`chokepoint6`），其余海峡仅存 duckdb 备用。
  原始日度镜像仅入 duckdb；**写 Excel 时按月聚合**。

### 3.18 Cloudflare Radar UAE 网络流量（source_cloudflare_radar.py）

- 数据源：Cloudflare Radar API（`/client/v4/radar/netflows/timeseries`），双指标：
  - **日度** `dateRange=90d&aggInterval=1d`（API 日度保留期约 90 天）；

### 3.19 RTA 迪拜交通（公交/水运/出租车，source_rta.py）

- 数据源：Data Dubai 开放门户（https://data.dubai ，Dubai Pulse 整合）上 RTA（道路与

## 5. 常见问题排查

| 现象 | 处理 |
|---|---|
| 合并报“工作簿被占用/权限” | 关闭 Excel 中打开的 `阿联酋.xlsx` 后重跑（脚本会自动从备份回滚） |
| 合并报“名称已被使用”或中文 sheet 乱码 | `data/UAE/scripts/*.ps1` 必须为 **UTF-8 带 BOM**；用编辑器改存可能剥掉 BOM 导致 PowerShell 按 GBK 读中文而删表失败，用记事本/VS Code 另存为“带 BOM 的 UTF-8”即可 |
| 合并偶发挂起/Excel 不退出 | 合并用 Excel COM 后台写表；若之前中断过，先打开任务管理器结束全部 `EXCEL.EXE` 再跑 `merge_workbook.bat` |
| 合并后 `日度_Wind`/`季度_Wind` 等 Wind 表数值变化 | 这是 Excel 原生重存时对 Wind 挥发性公式**重算**所致（旧流程同样如此）；管线从不写这些表，如需固定数值在 Wind 端处理后另行保存 |
| Comtrade 报缺少密钥 | 确认 `data/UAE/.env` 中 `COMTRADE_API_KEY=...` |
| 下载失败但想用旧数据 | 用 `--skip-download`，脚本只用 `raw/` 缓存解析入库 |
| 只想更新某个源 | `--source cbuae`（逗号分隔可多选） |
| 查看每次更新记录 | `SELECT * FROM meta_source_runs ORDER BY started_at DESC` |
| 数据库坏了 | 删除 `data/UAE/uae.duckdb` 后重跑 `data/UAE/scripts/update_data.bat`（DLD 依赖 `raw/dld/DLD.duckdb`
  迁移，因此不要删除 `raw/` 下的旧库与 CSV） |

## 6. 自动运行更新

两条命令（或用各自的 `.bat` 双击入口）均可无人值守运行；任何失败都会以非零退出码
结束并在输出中列出失败源，因此可安全交给“任务计划程序”定时执行。

### 6.1 最简单：双击 / 手动运行

```powershell
# ① 抓取→清洗→入库（默认只更新有网络下载环节的源；不加参数即全部）
.\data\UAE\scripts\update_data.bat

# ② 从库合并进 阿联酋.xlsx（务必先关闭 Excel 中打开的该工作簿）
.\data\UAE\scripts\merge_workbook.bat
```

### 6.2 定时自动更新（Windows 任务计划程序）

适用场景：每月数据源发布后自动更新数据库并写回工作簿，无需人工干预。

**准备工作**（只做一次）：

1. 把下面两个“自动运行”配置脚本放到 `data/UAE/` 下（或任意你指定的目录）。
2. 打开“任务计划程序”（Win+R → `taskschd.msc`）。

**创建两个任务**（按官方数据发布频率，建议错开时间）：

| 任务 | 触发（示例） | 要运行的程序 |
|---|---|---|
| ① 更新数据库 | 每月 5 日 06:00（覆盖多数月度源发布） | `runtime\python.exe` |
| ② 合并进工作簿 | 每月 5 日 06:30（在①之后） | `runtime\python.exe` |

任务“操作”→“新建操作”：

- 程序或脚本：`C:\Users\NIU\Desktop\HTFA_v1.1\runtime\python.exe`
- 添加参数：`-u "C:\Users\NIU\Desktop\HTFA_v1.1\data\UAE\scripts\update_data.py" --skip-download`
  （①）；`-u "C:\Users\NIU\Desktop\HTFA_v1.1\data\UAE\scripts\merge_workbook.py"`（②）
- 起始于：`C:\Users\NIU\Desktop\HTFA_v1.1`
- “设置”里勾选“如果任务失败，重新启动”；
- 运行用户建议用**当前账户**且勾选“只在用户登录时运行”或“不管用户是否登录都运行”
  （后者无需登录，但 Excel COM 写表需要可见会话，**推荐登录状态下运行**）。

> `--skip-download` 只解析 `raw/` 里的文件；若要自动联网下载原始文件则去掉该参数
> （注意 DLD 会重下约 1GB 全量 CSV，Comtrade 需要 `data/UAE/.env` 里的 API 密钥）。

**定时任务自动运行示例（.bat 包装，一个任务即可）**：

```bat
:: data\UAE\auto_update_all.bat —— 更新+合并一步完成
@echo off
cd /d "%~dp0..\..\.."
runtime\python.exe -u data\UAE\scripts\update_data.py --skip-download
if errorlevel 1 exit /b 1
if not exist runtime\python.exe exit /b 1
taskkill /IM EXCEL.EXE /F >nul 2>&1
runtime\python.exe -u data\UAE\scripts\merge_workbook.py
exit /b %errorlevel%
```

把上面的 `auto_update_all.bat` 放进“任务计划程序”：程序或脚本填该 .bat 完整路径，
操作/起始于可不填（脚本已用 `%~dp0` 定位仓库根目录）。这样**一个月一个任务**即可：
先更新库、再合并回 `阿联酋.xlsx`（任务内已先结束可能残留的 Excel 进程）。

### 6.3 验证与日志

- 每次更新在 `meta_source_runs` 表留痕：`SELECT * FROM meta_source_runs ORDER BY started_at DESC LIMIT 20;`
- 任务计划程序“上次运行结果”非 `0x0`（成功）即为失败，可查看该次运行输出。
- 合并前后脚本各自保留备份（`backups/` 下 `阿联酋_before_*_<时间戳>.xlsx`），异常时可回滚。
