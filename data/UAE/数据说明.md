# UAE 数据源更新说明

检查日期：2026-09-16
数据库：`data/UAE/uae.duckdb`  
工作簿：`data/UAE/阿联酋.xlsx`

## 1. 统一更新规则

所有指标都必须先写入 DuckDB，再由合并程序写入 Excel：

```text
原始文件 / 在线接口
        ↓ update_data.bat
data/UAE/uae.duckdb
        ↓ merge_workbook.bat
data/UAE/阿联酋.xlsx
```

常用命令：

```bat
htfa\jobs\uae_data\update_data.bat --source <来源名>
htfa\jobs\uae_data\merge_workbook.bat --source <来源名>
```

`--skip-download` 只读取 `data/UAE/raw/` 的已有缓存；不加该参数才会访问网站。`--force` 会忽略已有缓存并重新抓取。

`data/UAE/auto_update_all.bat` 只支持手动运行：每次运行都会在线检查/刷新所有可自动更新来源，
先把结果写入 DuckDB，最后统一合并工作簿。网络临时失败时，来源会保留并使用已经存在的有效缓存；
新文件的解析或字段结构发生变化时会在运行记录中报警，不会静默写入不完整指标。
本项目不创建、不依赖 Windows 任务计划或其他定时任务。

## 3. WAM 战争统计的全自动流程

联网执行：

```bat
htfa\jobs\uae_data\update_data.bat --source wam
htfa\jobs\uae_data\merge_workbook.bat --source wam
```

程序会依次：

1. 从 WAM 官方 sitemap 找到最近登记日之后的新文章；
2. 用本机 Chrome/Edge 渲染文章页，读取 `NewsArticle` 的 `articleBody`；
3. 提取弹道导弹、巡航导弹和 UAV 数量；
4. 对没有合格攻击文章的中间日期生成“官方 sitemap 未发现”的零行，并明确标记来源状态；
5. 将结果写入 `data/UAE/raw/wam/auto_daily_observations.csv`，再入 DuckDB；
6. 由 `merge_workbook.bat --source wam` 重建 `月度_WAM`。

自动缓存位于 `data/UAE/raw/wam/auto_articles.json`，文章 HTML 位于 `data/UAE/raw/wam/sources/`，均属于原始/缓存文件，不应提交到 Git。

程序只接受文章正文中可以明确归属到单日的高置信数字。类似“自冲突开始累计”“过去 48 小时共计”的数字不会被重复计入或擅自分摊；需要时会保留在来源缓存中供复核。

若本机找不到浏览器，可设置：

```bat
set WAM_CHROME_PATH=C:\Program Files\Google\Chrome\Application\chrome.exe
```

本次自动更新后，WAM 日度数据已从 2026-08-22 延长到 2026-08-31，新增 9 天；其中 8 月 31 日自动提取到 1 架 UAV。

## 4. 推荐操作顺序

1. 先准备人工来源的最新原始文件。
2. 手动运行 `data/UAE/auto_update_all.bat`（不带 `--skip-download`）。
3. 检查输出及 DuckDB 的 `meta_source_runs`，确认来源状态为 `ok`。
4. 关闭 Excel，运行 `merge_workbook.bat`。
5. 打开工作簿核对最新日期和指标值。

任何新增变量仍必须遵守“先入 DuckDB，再由合并流程写入 Excel”的规则。
