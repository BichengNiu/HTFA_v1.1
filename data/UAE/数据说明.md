# UAE 数据源更新说明

检查日期：2026-10-13
数据库：`data/UAE/uae.duckdb`  
工作簿：`data/UAE/阿联酋.xlsx`

## 1. 统一更新规则

所有指标都必须先写入 DuckDB，再由合并程序写入 Excel：

```text
原始文件 / 在线接口
        ↓ update_data.bat（在线抓取成功后入库）
data/UAE/uae.duckdb
        ↓ update_data.bat（按请求来源自动合并）
data/UAE/阿联酋.xlsx
```

常用命令：

```bat
data\UAE\auto_update_all.bat
htfa\jobs\uae_data\update_data.bat --source <来源名>
```

不加 `--skip-download` 时会在线抓取最新数据；`--skip-download` 只读取 `data/UAE/raw/` 的缓存。每次更新命令都会在 DuckDB 入库后合并所请求来源对应的工作簿工作表；单独运行 `merge_workbook.bat` 仅用于修复或重跑合并。`--force` 请求来源重新抓取。

`data/UAE/auto_update_all.bat` 只支持手动运行：每次运行都会在线检查/刷新所有可自动更新来源，
先把结果写入 DuckDB，最后统一合并工作簿。网络、资源发现、下载或解析失败会直接记录为失败并中止
Excel 合并，避免把旧 DuckDB 数据当作本次最新结果写回。只有显式使用 `--skip-download` 时才读本地原始缓存。
本项目不创建、不依赖 Windows 任务计划或其他定时任务。

### 2.2 首次运行前的一次性配置

| 来源 | 一次性准备 | 后续更新行为 |
|---|---|---|
| Cloudflare Radar | 将 `CF_RADAR_TOKEN` 放入环境变量或 `data/UAE/.env` | 每次更新自动请求 API；原始 JSON 保留在 `raw/cloudflare_radar/` |
| UN Comtrade | 将 `COMTRADE_API_KEY` 放入 `data/UAE/.env` | 自动刷新设备和车辆序列；API 失败会直接报错 |
| WAM / US DOT T-100 | 安装 Chrome/Edge；T-100 首次运行需可联网下载 Playwright | 后续自动发现、渲染或下载官方数据 |

Google Trends 文档化 API 目前为限量 alpha，因此 `employment` 使用 Google Trends 网站图表的 JSON 接口自动取数；该接口未承诺稳定，若网站协议变化需更新解析器。一次性凭据配置完成后，不需要每次手动准备原始文件。

| 来源 | 自动部分 | 仍需人工的部分 |
|---|---|---|

## 3. WAM 战争统计的全自动流程

联网执行：

```bat
htfa\jobs\uae_data\update_data.bat --source wam
```

程序会依次：

1. 从 WAM 官方 sitemap 找到最近登记日之后的新文章；
2. 用本机 Chrome/Edge 渲染文章页，读取 `NewsArticle` 的 `articleBody`；
3. 提取弹道导弹、巡航导弹和 UAV 数量；
4. 对没有合格攻击文章的中间日期生成“官方 sitemap 未发现”的零行，并明确标记来源状态；
5. 将结果写入 `data/UAE/raw/wam/auto_daily_observations.csv`，再入 DuckDB；
6. `update_data.bat` 自动从 DuckDB 合并并重建 `月度_WAM`。

自动缓存位于 `data/UAE/raw/wam/auto_articles.json`，文章 HTML 位于 `data/UAE/raw/wam/sources/`，均属于原始/缓存文件，不应提交到 Git。

程序只接受文章正文中可以明确归属到单日的高置信数字。类似“自冲突开始累计”“过去 48 小时共计”的数字不会被重复计入或擅自分摊；需要时会保留在来源缓存中供复核。

若本机找不到浏览器，可设置：

```bat
set WAM_CHROME_PATH=C:\Program Files\Google\Chrome\Application\chrome.exe
```

本次自动更新后，WAM 日度数据已从 2026-08-22 延长到 2026-08-31，新增 9 天；其中 8 月 31 日自动提取到 1 架 UAV。

## 4. 推荐操作顺序

1. 首次运行前配置所需 API 凭据，并确保 Excel 工作簿已关闭。
2. 手动运行 `data/UAE/auto_update_all.bat`（不带 `--skip-download`）。
3. 更新命令会自动抓取所有来源、写入 DuckDB 并合并对应工作表。
4. 检查命令输出及 DuckDB 的 `meta_source_runs`，确认每个来源状态；任一更新失败时本次不会合并 Excel。
5. 打开工作簿核对最新日期和指标值；单独运行 `merge_workbook.bat` 仅用于修复或重跑合并。

任何新增变量仍必须遵守“先入 DuckDB，再由合并流程写入 Excel”的规则。
