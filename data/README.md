# 本地数据目录

`data/` 中的原始资料、工作簿、数据库和生成结果只保存在本机，不推送到 GitHub。
各数据来源子目录的 `README.md` 仍由 Git 管理，用于记录来源、文件命名和更新方法。

可复现的数据更新代码位于 `scripts/data_sources/`：

- `baker_hughes/`：Baker Hughes 月度钻机数据；
- `cbuae/`：阿联酋央行月度统计公报；
- `gfs/`：阿联酋财政部政府财政统计。

首次克隆仓库后，需要从本地备份恢复实际数据文件，或者依据各来源目录中的说明重新下载。不要提交用户数据库、临时导出文件或包含敏感信息的数据。
