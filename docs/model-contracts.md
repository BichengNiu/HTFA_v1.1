# 模型与统计口径

## 后端与候选调度

- 绘图和模型能力遵循根目录 `AGENTS.md` 的 Ts 优先流程。HTFA 负责界面与状态适配，复用 Ts 的公共数值接口；不得复制后端算法。
- 自动 SARIMAX 与 RDL 候选使用 Ts 的受限自适应进程调度。小于 8 个候选或工作量过低时串行；其他搜索最多 4 个单线程数值工作进程，至少保留一个逻辑核。不得拆分单模型优化或造成 BLAS 过度订阅。
- 候选顺序与最优选择必须可复现；准则选择与具体候选覆盖互斥，候选表任意一行均可作为最终拟合模型。

## 页面交接与模型库

- 独立动态回归页通过短期、不透明的进程内令牌复制文件、读取设置、可编辑输入和当前拟合、诊断、预测结果；结果不进入 URL。
- 交接结果必须深拷贝。独立页初始显示与复制时一致，后续可变对象和结果生命周期由各自会话管理。
- 用户显式保存的 SARIMAX、RDL、ARDL 模型由同一模型库标识关联的页面共享；模型库操作不得回写各页面当前结果。
- 模型记录保存拟合对象的深拷贝，以及数据集身份、输入、签名、记录编号、名称和保存时间。参数、残差、拟合值、信息准则与阶数从模型对象读取，不重复保存统计结果。
- 同签名记录覆盖更新。模型库只在进程内保存，重启后清空；不提供磁盘恢复、导入导出、跨服务共享或自动淘汰。

## 评估与模拟

- 当前预测窗口分开报告训练期拟合表现与训练结束后的样本外表现；训练指标不得代替样本外能力。
- 历史滚动回测采用扩展窗口、一步预测、逐期滚动；不得使用未来目标值拟合当前预测起点。外生变量使用已观测未来路径时须明确标注为条件评估。
- 主误差表展示 MAE、RMSE、MPE、MAPE、sMAPE；方向命中率、相对朴素基准胜率、趋势相关系数分别展示，不混合成总分。
- 无真实值的期次不评分；展示有效样本数与覆盖率。log 模型统一在原始尺度评分。
- RDL 干预变量使用观测日历上的 0/1 外生变量：pulse 为单期，step 从冲击日起持续，temporary 为含起止日期的闭区间；不得改写原始 X。
- 模拟路径分布仅用于纯 SARIMAX。确定性响应叠加 TsSims 随机误差路径，log 模型还原原始尺度；实际线使用训练范围和预处理后的实际建模序列。
- 模拟使用 95% 中心区间；均值、方差、ACF、转折点数量分别与模拟分布比较。模拟失败不得使已有拟合结果失效。

## 赫斯特指数

- 对当前选中的原始数值变量调用 TsUtils 经典重标极差 R/S 方法；缺失值删除，不插值。
- 有效观测不足 20 个、常数序列或无法形成有效分块时不返回数值。展示有效观测数，并保留短样本、结构变化敏感性的解释。
- H 与 0.5 的比较只作描述性参考，不作为平稳性检验、因果关系或预测能力结论。
