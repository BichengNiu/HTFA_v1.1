# UAE 低频停滞指标复核（2026-11-03）

本次检查针对仍停在2026年9月及以前的已接入来源。在线重新发现目录、下载或核对官方文件，并在隔离 DuckDB 副本重跑下载、解析和入库；只有校验后的库才用于重建 Excel 和报告快照。原始下载、逐项运行结果和失败证据保存在本地，不提交缓存或凭据。

## 已修复的脚本问题

- FCSC 季度 GDP 的原始文件名 `CON.csv` 命中 Windows 保留设备名，下载临时文件无法替换目标。改为 `gdp_CON.csv` / `gdp_CUR.csv`，来源地址及经济定义保持一致，并增加真实下载路径的回归测试。现价、不变价分别按官方各自最新季度保留。
- Cloudflare 周度数据用周一时间戳推断整月覆盖，错误地将已经完整覆盖10月的接口结果截回9月。现在先把接口 `meta.dateRange.endTime` 的排他终点换算为覆盖日入库，再依据该来源文件的覆盖日期判断完整月份。补入9月28日、10月5日、12日、19日四周；10月26日一周跨入11月，继续排除。缺少覆盖证据时保持保守边界。
- DLD 下载元数据接口偶发 HTTP 200 但正文不是 JSON，第一次在线复核因此失败。增加最多三次实时请求；持续异常仍报错，不自动回退旧缓存。再次成功取得目录后，完整下载11月2日两个分片，校验 SHA-256 并从1,811,462笔交易重建底表。新快照实际交易日期仍只到10月30日，未覆盖10月31日，所以完整月/周规则继续保留9月展示边界。

## SCAD 酒店撤下

按用户要求，移除 `scad` 活动更新/合并入口、`scad_monthly` 表、`月度_SCAD` 工作表及对应元数据。旧 `月度_Wind` 中同属阿布扎比统计局的酒店重复列也移除。历史运行日志和本地原文保留；普通 `all` 不会重新引入。其他 SCAD 定义和非酒店指标不受这条筛选影响。

## 不能宣称“所有旧列均自动更新”

旧 Wind 工作表还保留一些未接入自动脚本的原始序列，包括金联创原油现货、ICE连续期货、隆众成品油/化工、印度咖啡、海关对阿贸易及同比环比、GCSP港口服务、部分世界银行市场指数、DFM行业成交、美国财政部相关序列。它们仍有2026年3—8月截止记录，部分定义与新增公开来源不同。对这些列，“没有对应更新任务”与“已接入任务失效”必须分开，不能用新表最大日期替它们背书，也不能静默换成不同口径。

下面附发布后逐列清单；重复名称按原表列分别列出。日期取最后非零记录，仅用于发现旧 Wind 常见的尾部补零，并不把经济上有效的零值从正式数据中删除。
