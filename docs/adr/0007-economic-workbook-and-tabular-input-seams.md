# 经济工作簿与普通表格输入使用独立协议

**Status:** accepted

经济工作簿与普通表格数据集使用两个独立且唯一的输入协议。经济工作簿协议拥有指标字典、元数据和经济数据缺失规则；普通表格协议保留用户表格的原始数值语义，包括 `0`，不能因为文件格式相同就套用经济工作簿规则。两者只共享无业务含义的字节读取、日期解析等基础能力。

**Considered Options:** 一个万能 parser；经济工作簿 parser 作为普通表格 parser 的回退；两个明确协议。选择最后一种，因为格式相同不代表业务语义相同，解析失败也不能让输入悄然改变口径。

**Consequences:** 输入失败必须 fail-closed 并清理旧分析数据；调用方必须显式选择协议；新的普通表格输入不得依赖经济工作簿目录或业务 whitelist。
