# 单变量模型预测精度评估口径

**Status:** accepted

单变量模型（SARIMAX、RDL、ARDL）统一提供当前预测窗口评估和历史滚动回测。当前窗口将训练区间标为“拟合表现”，将训练结束日后的、有真实值的区间标为“样本外表现”；历史回测采用扩展窗口、一步预测、逐期滚动，并以朴素基准计算相对基准胜率。主误差表只展示 MAE、RMSE、MPE、MAPE、sMAPE；方向命中率、相对基准胜率和趋势相关系数单独展示。没有真实值的日期不计入评分，并明确展示有效样本数和覆盖率；启用 log 的模型统一在原始尺度上评分。

这一口径的结果是：训练期指标用于判断拟合表现，不能替代样本外能力；当前预测窗口不等同于历史泛化检验；方向性指标用于补充判断，不与误差指标混成单一总分；外生变量历史回测使用观测到的未来路径，并在页面明确标注这是条件评估。
