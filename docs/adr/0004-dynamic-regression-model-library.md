# 动态回归模型库采用进程内共享存储

模型分析中的 SARIMAX、RDL 和 ARDL 拟合结果可以由用户显式保存为模型记录。主页面与其独立动态回归模型页通过同一个不透明标识访问同一份进程内模型库；当前拟合、诊断和预测结果仍保留在各自页面会话中，不因模型库操作互相回写。

模型记录保存拟合模型对象的深拷贝，并只保存数据集身份、模型输入、模型签名、记录编号、用户名称和保存时间等来源及管理元数据。参数、残差、拟合值、信息准则和模型阶数继续从模型对象读取，避免维护重复统计值。

选择进程内存储是因为第一版只服务单用户，目标是为后续性能比较提供稳定的运行时对象边界，而不是建立持久化模型仓库。代价是服务重启后模型库清空；因此不提供磁盘恢复、导入导出、跨服务共享或自动淘汰。
