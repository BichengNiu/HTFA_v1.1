# UAE 采用数据、处理计算和显示三层架构

**Status:** accepted

UAE 遵循能源保供 ADR-0010，在同一进程中使用 `ui → processing → data`。
共享 `contracts` 仅承载类型、指标协议和静态定义，不执行 I/O。

数据层负责只读 DuckDB 发布快照、版本及经济工作簿协议校验；快照描述本身
不再提供打开数据库的方法，经济工作簿读取器通过数据层内部适配器接入。
处理层负责聚合、日期窗口、同比环比、单位转换和下载数据构建，不依赖
Streamlit、Matplotlib、Ts 或数据库执行接口。显示层负责页面、绘图、打印、
下载按钮和缓存；缓存身份包含数据库绝对路径及发布版本。

遵循 ADR-0008，一次性更新全部调用方并删除旧路径，不保留兼容模块。
页面及统计口径保持不变；主题失败隔离、缺失值语义、来源校验和发布失败
回滚继续保留。维护作业仍属于 `htfa/jobs/uae_data/`，数据必须先入 DuckDB
再合并至 Excel。模块导入不得触发数据库或网络访问。

**Consequences:** 依赖方向、循环依赖、导入安全与旧路径清零由架构测试约束。
