# 阿联酋经济监测模块设计说明

**版本：** 1.0  
**日期：** 2026-07-29  
**状态：** 设计已确认，尚未实施  
**目标模块：** `dashboard/analysis/uae/`

## 1. 模块定位

阿联酋经济监测模块不是原始数据浏览器。原始序列、元数据、频率和数据质量由
`dashboard/preview/` 展示；监测模块负责基于宏观经济核算关系解释总量指标变化。

模块必须连续回答五个问题：

1. 结果变量发生了什么变化？
2. 哪些核算分项贡献了变化？
3. 变化发生在哪些行业和制度部门？
4. 哪些经济机制和高频证据支持这一解释？
5. 变化是暂时的、周期性的还是结构性的，结论置信度如何？

统一诊断链为：

```text
结果变量变化
    → 核算恒等式拆解
    → 行业与制度部门定位
    → 经济机制与传导渠道
    → 交叉验证、持续性与风险
```

### 1.1 与其他模块的边界

| 模块 | 职责 | 不承担的职责 |
|---|---|---|
| Preview | 原始数据、元数据、频率、缺失值和时间范围预览 | 不解释经济原因 |
| Monitoring | 核算贡献、机制证据、持续性判断和诊断叙事 | 不提供任意原始变量浏览 |
| Explore | 相关性、领先滞后、平稳性、结构突变等用户探索 | 不自动生成宏观结论 |
| Models | 预测、新闻分解、情景或结构模型 | 不代替核算恒等式 |

## 2. 分析对象的层级

### 2.1 宏观结果

需要解释的结果变量包括：

1. 经济增长与经济结构；
2. 通货膨胀；
3. 就业、工资与居民实际收入；
4. 财政状况；
5. 国际收支与外部平衡；
6. 货币、信贷与金融稳定。

### 2.2 行业

行业回答“增加值在哪里产生”，对应生产法国民账户。初始行业分组为：

- 石油和天然气；
- 制造业；
- 建筑业；
- 房地产；
- 批发零售；
- 交通运输与仓储；
- 住宿餐饮与旅游；
- 信息通信；
- 金融保险；
- 专业和商业服务；
- 其他服务。

### 2.3 制度部门

制度部门回答“谁在消费、投资、储蓄、借贷和承担风险”，对应国民账户制度部门：

- 居民部门；
- 非金融企业；
- 金融机构；
- 一般政府；
- 国外部门。

行业和制度部门不得混用。行业用于解释生产和增加值，制度部门用于解释收入、需求、
储蓄、融资和资产负债表变化。

## 3. 证据等级与允许表述

每一条自动诊断必须标记证据类型。

| 证据类型 | 定义 | 允许表述 | 禁止表述 |
|---|---|---|---|
| 核算事实 | 由恒等式或可加总分项直接计算 | “制造业贡献了非油增长的……” | “制造业导致了全部增长” |
| 机制证据 | 与理论机制方向一致的观测证据 | “工资与信贷变化支持消费改善的判断” | “工资上升必然导致消费增加” |
| 领先信号 | 尚未进入结果变量的高频或预期指标 | “新订单显示下一季度动能可能改善” | “下一季度一定加速” |
| 模型估计 | 有明确模型、假设和误差范围的结果 | “模型估计该因素解释……” | 隐去假设后作为事实陈述 |

### 3.1 置信度

诊断置信度由规则计算，不由撰写者主观指定。

| 等级 | 最低条件 |
|---|---|
| 高 | 核算分项覆盖充分；数据口径一致；数据较新；至少两项机制证据方向一致 |
| 中 | 核算分项存在残差或频率不完全一致，但主要结论有独立证据支持 |
| 低 | 主要依赖代理变量、区域数据或低频数据，或证据之间明显冲突 |

总览页不得隐藏“低置信度”，也不得为了形成单一结论而消除相互冲突的证据。

## 4. 一级页面结构

### 4.1 经济总览

总览页只展示六个诊断结果：

- 增长；
- 通胀；
- 就业收入；
- 财政；
- 外部平衡；
- 货币金融。

每张诊断卡使用固定字段：

```text
结果：结果变量的方向、幅度和时间窗口
核算贡献：可加总分项中的主要正负贡献
机制证据：支持或反驳解释的高频证据
持续性：暂时性、周期性、结构性或无法判断
置信度：高、中、低及降级原因
数据截止：结果变量和机制变量分别标记
```

不建立单一“阿联酋经济综合指数”。不同结果变量可能同时发出不同信号，透明呈现冲突
比压缩成一个分数更符合监测目的。

### 4.2 经济增长与结构

#### 结果变量

- 实际GDP同比和环比；
- 非油GDP增长；
- 人均实际GDP；
- 劳动生产率；
- 潜在增长和产出缺口，作为后期模型功能。

#### 生产法

```text
GDP = 各行业增加值之和 + 产品税 - 产品补贴
```

展示油与非油贡献、行业贡献、增长扩散度、经济结构和未覆盖残差。只有在同一价格口径、
同一频率且满足加总关系时，才生成增长贡献。

#### 支出法

```text
GDP = 居民消费 + 政府消费 + 固定资本形成
    + 库存变化 + 出口 - 进口
```

用于判断增长来自消费、投资、政府需求还是净出口。公开数据频率不足时，只展示年度结构，
不得用高频代理变量冒充季度支出法贡献。

#### 收入法

```text
GDP = 劳动者报酬 + 营业盈余和混合收入 + 生产税净额
```

用于判断增长收益主要体现为工资、企业利润还是政府收入。

#### 机制渠道

1. 石油：产量和国际油价影响石油增加值、出口和财政；
2. 居民消费：就业、工资、人口、消费信贷和支付活动；
3. 企业投资：利润预期、PMI、新订单、企业信贷、建筑和房地产；
4. 政府需求：政府消费、资本开支和财政转移；
5. 外部需求：非油出口、转口贸易、旅游、航空和物流。

### 4.3 通货膨胀

#### 结果变量

- CPI同比；
- CPI环比；
- 三个月年化动量；
- 商品与服务通胀；
- 住房与非住房通胀；
- 系统派生的核心通胀。

自行排除食品、能源等分类得到的指标必须标为“系统派生”，不得标为官方核心通胀。

#### 核算拆解

```text
分类贡献 ≈ 对应时期权重 × 分类价格变化
```

分类采用COICOP，至少包括住房、食品、交通、餐饮住宿、教育、医疗及其他商品服务。
贡献计算必须处理权重和基期变化，禁止把当前权重静默回填到全部历史时期。

#### 机制解释

国内因素：

- 房租和房地产价格；
- 工资和单位劳动成本；
- 非油产出缺口和PMI；
- 政府支出；
- 货币与信贷增长。

外部因素：

- 美元名义有效汇率；
- 全球食品与非能源商品价格；
- 石油价格和国内燃料价格；
- 国际运输成本；
- 美联储和阿联酋利率。

### 4.4 就业与居民收入

#### 核算链

```text
人口 → 劳动年龄人口 → 劳动力 → 就业人口

劳动收入 ≈ 就业人数 × 平均工资
实际劳动收入 = 名义劳动收入 / CPI
劳动生产率 = 实际GDP / 就业人数
```

页面需要区分：

- 全经济劳动力调查；
- WPS覆盖的私营部门雇员；
- 阿联酋公民和非公民；
- 名义工资和实际工资；
- 就业数量和就业质量。

WPS数据不得表述为全国全部就业或全部居民收入。

### 4.5 财政与外部平衡

页面分为两个独立页签。

#### 财政

```text
净借贷/净借款 = 收入 - 支出 - 非金融资产净购置
```

拆解税收、社会缴款、其他收入、雇员报酬、商品服务支出、补贴、社会福利、利息、
资本支出、金融资产和负债。

宏观财政立场使用“合并一般政府统计”。联邦预算只用于解释联邦层面的支出结构，不能
代替全国财政立场。

后期可在数据满足条件时计算：

- 非油初级余额/非油GDP；
- 财政脉冲；
- 油价对财政收入的敏感性；
- 债务和政府金融资产缓冲。

#### 外部平衡

```text
经常账户 = 货物 + 服务 + 初次收入 + 二次收入
```

进一步拆解：

- 油气出口的价格和数量效应；
- 非油出口和转口贸易；
- 旅游和运输服务；
- 投资收入；
- 个人汇款；
- 外国直接投资、证券投资和其他投资；
- 储备资产。

月度贸易、航空、旅游、汇款和储备只作为年度或季度国际收支的交叉验证，不得自动拼接
成未经官方确认的经常账户估计。

### 4.6 货币、信贷与金融稳定

阿联酋固定汇率制度下的主要传导链为：

```text
美联储利率 → CBUAE基础利率 → DONIA/EIBOR
            → 存贷款利率 → 信贷、需求和资产价格
```

以及：

```text
国际收支和资本流动 → 外汇储备和基础货币
                    → 银行流动性、存款和信贷
```

需要监测：

- CBUAE基础利率、DONIA和EIBOR；
- M1、M2、M3；
- 居民和非居民存款；
- 政府、政府相关实体、企业和居民信贷；
- 按行业银行信贷；
- 贷存比和银行国外资产负债；
- 不良贷款率、资本充足率、流动性覆盖率、ROA和ROE；
- 信贷需求和银行授信标准；
- 房地产价格、交易、按揭和建筑信贷；
- DFM、ADX及市场流动性。

## 5. 页面阅读契约

所有详细页面保持相同阅读顺序：

1. **诊断结论**：一句话说明结果、主要贡献、支持证据和置信度；
2. **结果变量变化**：同比、环比、加速度和历史区间位置；
3. **核算贡献**：使用瀑布图或可加总贡献图；
4. **行业与部门定位**：识别变化发生的位置和行为主体；
5. **机制证据**：展示3—6个最相关的高频指标；
6. **持续性与风险**：区分基数、短期冲击、周期和结构变化；
7. **证据与限制**：标明数据范围、频率、修订和代理变量。

页面不提供大规模原始数据表。用户需要查看具体数值和元数据时，跳转到Preview；需要做
自由统计分析时，跳转到Explore。

## 6. 自动叙事规则

自动叙事采用确定性模板，不依赖大模型自由生成。

推荐句式：

```text
[结果变量]在[时期]较[比较期][上升/下降][幅度]。
核算上，[分项A]和[分项B]分别贡献[数值]和[数值]，
[分项C]形成[数值]的拖累。
[机制变量D]与[机制变量E]的变化与[机制解释]一致，
但由于[数据限制]，目前不能识别[不能推出的结论]。
结论置信度为[等级]。
```

词语约束：

- 核算事实使用“贡献”“拖累”“占比”；
- 机制证据使用“与……一致”“支持……判断”“未提供支持”；
- 领先信号使用“显示未来动能可能”；
- 无正式识别时禁止使用“导致”“造成”“决定”。

## 7. 数据与计算规则

1. 同比和环比不能混合解释；
2. 季度环比必须标明是否经过季节调整；
3. 名义贡献和实际贡献必须分开；
4. 石油GDP由“总GDP减非油GDP”推导前必须验证恒等式；
5. 行业覆盖不完整时必须保留“其他/税收与残差”；
6. CPI贡献使用对应时期权重和指数方法；
7. 高频变量只作交叉验证或领先信号；
8. 不同频率数据分别标记最新观测期和发布日期；
9. 不静默前向填充结果变量；
10. 初值、修订值和终值必须标记；
11. 全国、酋长国和特定样本必须显式标记覆盖范围；
12. 证据冲突时保留冲突并降低置信度。

## 10. 分期建设

### 第一阶段：增长诊断

- 总量、油与非油拆解；
- 行业实际增长贡献；
- 名义—实际桥接；
- 行业扩散度；
- 残差和口径检查；
- 确定性诊断叙事。

### 第二阶段：通胀与货币金融

- CPI分类贡献；
- 国内和外部通胀机制；
- 利率—流动性—信贷传导；
- 信贷行业结构。

### 第三阶段：就业、财政和外部平衡

- 全经济劳动力与WPS交叉验证；
- 合并一般政府财政；
- 国际收支和月度贸易；
- 居民、企业、政府和国外部门联动。

### 第四阶段：高级分析

- 产出缺口；
- 非油初级财政余额；
- 通胀驱动模型；
- 混合频率即时预测；
- 情景分析和压力测试。

第一阶段验收前不进入第二阶段。后续阶段的数据接入仍使用同一工作簿协议和指标字典，
不建立第二套平行解析器。
