# 阿联酋经济监测变量字典

**版本：** 1.0  
**日期：** 2026-07-29  
**用途：** 定义监测模块需要的结果变量、核算分项、机制变量和领先指标，并区分当前
工作簿已有数据与后续待补数据。

## 1. 字段和状态

实施时每个指标还必须保留现有工作簿协议要求的频率、单位、来源和更新时间。

| 字段 | 含义 |
|---|---|
| 指标ID | 稳定的内部语义标识，不随展示名称变化 |
| 指标或系列族 | 需要加入指标字典的变量或同口径系列组 |
| 角色 | 结果、核算分项、机制证据、领先信号、风险指标 |
| 频率 | 推荐的原始发布频率，不表示系统强制重采样 |
| 覆盖 | 全国、酋长国或特定统计样本 |
| 来源 | 优先数据发布机构 |
| 状态 | 当前工作簿是否具备 |
| 优先级 | P0为第一阶段必要，P1为下一阶段，P2为增强项 |

状态定义：

| 状态 | 定义 |
|---|---|
| 已有 | 当前 `data/阿联酋.xlsx` 已包含 |
| 可计算 | 可由当前已有变量按明确公式派生 |
| 待补-官方 | 已核验存在官方公开来源 |
| 待补-公开受限 | 公开发布，但历史序列、授权或机器可读性存在限制 |
| 待核验 | 概念必要，但稳定公开序列仍需逐表确认 |
| 低频 | 有调查或年度数据，但不适合作为连续高频监测结果 |

当前工作簿共89个指标：日度1个、月度1个、季度84个、年度3个。季度数据主要由
GDP总量、非油/非金融总量和11个行业的名义值、实际值、同比、环比构成。

### 9.1 行业增长质量诊断口径

- 数据只使用工作簿中的16个行业季度不变价增加值与非油实际GDP；行业现价增加值不参与本组诊断。
- 行业同比增速为 `100×(Y_i,t/Y_i,t-4-1)`；加权指标统一使用上年同期权重 `Y_i,t-4/Y_nonoil,t-4`，每个可计算季度的权重必须加总为1。
- 扩张广度后台分别统计：同比正增长、高于自身截至上季的扩展历史均值、同比增速较上季度加快、连续四季度同比正增长，并保留等权与加权派生结果。图表仅展示不加权的“正增长行业比例”和“连续四季度正增长行业比例”；任一行业缺失时整季保留为空，不缩小16行业分母。50%与80%参考线按16个行业的等权比例解释。
- 集中度地图的横轴为贡献平衡指数 `Σcᵢ/Σ|cᵢ|×100`：－100表示全部为负贡献，0表示正负贡献完全抵消，100表示全部为正贡献。
- 纵轴先按全部16个行业的贡献绝对值计算 `HHI=Σ(|cᵢ|/Σ|cᵢ|)²`，再转换为标准化绝对贡献集中度 `(HHI－1/16)/(1－1/16)×100`；0表示16行业等额变动，100表示单一行业主导。该口径在增长期和收缩期含义一致。
- 气泡面积为总变动强度 `Σ|cᵢ|`，单位为百分点；它用于区分轻微波动和强烈行业重配，不能解释为净增长率。悬浮信息同时报告非油GDP同比、绝对贡献HHI及最大正负贡献行业。
- 行业贡献不完整或全部行业贡献均为0时，贡献平衡指数、集中度和总变动强度统一为空，该季度不进入集中度图。
- 集中度图使用Plotly内置季度时间轴：每个frame保留截至所选季度的历史气泡，并以深色描边突出当前季度；拖动滑块、从头播放或暂停均不重新估计指标。
- 集中度纵轴指标的理论范围为0—100。实际显示上限根据完整样本最大值留出20%余量后向上取整到5的倍数，最低为20、最高为100；该范围在全部季度frame中固定，既避免低集中度观测贴近横轴，也不通过逐帧缩放夸大跨期变化。
- 状态矩阵以当季增速相对截至上季的自身历史均值判断高位/低位，以当季同比相对上季度同比判断加速/放缓（改善/恶化），展示最新完整季度；悬浮信息同时保留最近4季、最近8季、连续正增长和高于历史趋势次数。
