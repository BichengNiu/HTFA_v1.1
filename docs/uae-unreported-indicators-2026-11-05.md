## 可复核的依据

- 发布指标全集来自DuckDB的`report.sheets.heading`及`report.observations`；统计键为表名和原始列位置，不按名称粗略去重。
- 实际执行五个高频主题和年度渲染，捕捉共享目标读取器成功匹配的列位置；记录41次图表输出且没有主题错误或数据警告。季度与行业39个源列按语义适配器的实际解析结果登记。
- 年度数据按`ANNUAL_CHARTS`及最新年固定前五项规则，并实际读取下载按钮的CSV表头，区分图上输入与仅下载列。资本形成下载只含现价及其同比，不变价列已按用户要求停用。
- 完全未使用清单有103行，年度仅下载清单有224行；两者互斥，且与其余139列合计466列。
- 生成时的查询、运行脚本及逐列结果保留在本地`.cache/uae-pruning-2026-11-05/`，不入Git。

核心观测覆盖查询：

```sql
SELECT s.sheet_name, o.column_index, MIN(o.period), MAX(o.period), COUNT(*)
FROM report.observations o
JOIN report.sheets s USING (sheet_index)
GROUP BY s.sheet_name, o.column_index;
```
