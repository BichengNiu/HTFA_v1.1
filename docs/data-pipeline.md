# 数据管线约束

## 存储与发布

- 所有新增指标必须先写 `htfa/monitoring/uae/assets/uae.duckdb`，再经来源 `merge()` 从库写入 `htfa/monitoring/uae/assets/阿联酋.xlsx`。禁止绕过数据库直接改指标数值；指标字典只在合并时同步。
- 数据库中的来源事实、明细、能源事实和报告快照用途不同，不能因页面未直接展示就删除。是否用于图表、指标卡、计算输入、下载或仅作核验须分别判断。
- Excel 仍包含来源作业未覆盖的历史指标，发布流程校验工作簿后原子写入 `report` 表；不得将其当成可随意删除的临时文件。
- 页面只读已发布快照。缺库、无效发布或 Git LFS 指针未下载时明确报错，不在页面初始化表、采集或发布。
- 维护作业持有发布锁，在候选数据库与工作簿上执行；每来源失败或超时恢复该来源完整检查点，成功来源可继续。最终校验失败保留生产文件；数据库与 Excel 成对安装。
- 历史完整性按业务主键、工作表、指标名、重名出现次数和观察期验证；拒绝旧键消失、旧非空值被清空、来源末期倒退。总行数相同或最早／最晚日期不变不代表历史完整。
- CBUAE、外籍劳工按主键合并，短缓存不得整表替换历史；响应未覆盖的旧键及旧有效值的来源必须保留。菲律宾 YTD 仅能用紧邻上月差分，缺月时失败，不将跨月差额当单月值。
- 停用指标以 `retired_indicators.json` 为维护名单，先入 DuckDB，再按指标名合并删除工作簿列和字典；活动与退役来源以 `source_registry.py` 为准，不从历史报告恢复来源。

## 资产归属与原件保留

- UAE 资产统一存于 `htfa/monitoring/uae/assets/`；UAE 页面、能源保供与维护作业共享模块契约中的默认路径。`HTFA_UAE_DATA_DIR` 只用于维护候选目录，不改变在线页面生产库位置。
- 根目录不保留旧 UAE 数据入口或双读路径。Git LFS、云端采集缓存、精确提交验证、Docker 挂载与清理保护必须使用新位置。
- `raw/`、密钥与本地研究数据不入 Git 或镜像。有效来源仍需读取的原件不因事实入库而删除；不参与当前统一更新的停用来源、独立研究资料和旧诊断输出，可以按用户明确指令清理。
- 清理范围必须同时核对自动与手动更新入口及辅助依赖，不把季度、年度来源因未列入每日调度而删除。有效来源的离线更新仍按完整清单校验，不用缺失原件拼出不完整历史；清理后核对生产数据库／工作簿未变。

## 来源与完整性

- 在线失败不得使用未知版本旧缓存冒充成功。`--skip-download` 是显式离线读取；原始件、缓存、清单、备份、日志及凭据不入 Git。
- 下载清单指定的分片必须齐全；执行源版本、内容哈希、大小、记录数、唯一键及字段校验。下载临时文件校验后原子替换，失败保留上次有效输入。
- RTA 离线只读各数据集清单指定文件并核对大小，不扫描混用历史版本；公交速度 CSV 保留完整字段和记录，水运读取官方 JSON 的完整日期字段，缺失、重复或无效日期报错。
- 海关航空按当前完整清单下载，支持断点续传，校验响应长度和 gzip CRC；缺分片拒绝入库。PortWatch 核验发布者、权限、图层、版本和前后全量 ID 集合，分批成功不能代表整源成功。
- WAM 累计值与跨日区间不得分摊为虚构单日值；本地 CSV 缺失时只从校验通过的发布历史续采，不从空历史补造事件。
- 业务缺失保留为空值，不以零填充。月末标签不表示事件已覆盖完整月份；运行时间不替代实际观测日期。未接入来源不得用其他表的新日期或不同口径背书。
- 能源事实存于同一数据库的 `energy_supply` schema。采集港口、通道和 AIS 时保留完整交付与来源新鲜度校验；日快照不代表连续船位覆盖。
- PortWatch 月度指标是已观测日合计；已观测日字段缺失时月值留空。AIS 月度指标是水域内已观测 MMSI 去重数，不代表全部通行量。

## 特殊指标口径

- CBUAE 企业部门未单列商业及工业部门时，按已核实恒等式“私人企业 Corporate − 其他金融企业 Other Financial Corporations”推算；非居民存款取对应非居民块，禁止跨口径相减。
- Emsteel 指标是 AED/吨、不含 VAT 的 EXW 名义公开报价汇编，不是市场成交均价，也不保证各月规格完全相同。不得混接不同交货条款或对冲突报价自行平均。
- Quanto 仅取 `emsteel-xw` 的 `published` 记录，拒绝重复月份并排除 `excluded`；缺月只允许有明确原文依据的报价差额、不变价回溯或同文汇率折算，不插值、静默前填或填未来月份。
- Emsteel 的来源 URL、原文哈希、原币、汇率和质量标记先入库，写表时保留批注。须区分直接报价、差额／沿用推算、口径／年份推断、汇率折算、第三方汇编及第三方均值；保留报价冲突与优惠安排变化的限制。
- WDI 海合会比较使用六国简单平均，缺任一国留空，不变样本平均、不加权、不插值；现价金额和实际增速分开，三产业占比不强制归一到 100%。

## 调度与远端验证

- UAE 与能源采集共用 `.github/workflows/energy-supply.yml` 的每日调度；保活独立，写入共用 `htfa-main-writer` 并发组，不取消正在发布的作业。
- 更新范围以 `source_registry.py`、`daily_refresh.py` 为准。能源更新必须实际采集，不以重算旧事实宣称完成在线更新；部分成功须明确列出失败来源，全部失败不发布。
- 云端只提交数据库和工作簿，不强推或合并数据库二进制；采集中远端变化则丢弃候选，从新版本有限重试。
- 推送后核对远端提交，并下载精确提交对应的 LFS 对象验证大小与 SHA-256。存储校验通过不等于经济历史完整，两者均须通过。
- 凭据通过本地 `.env` 或云端 Secrets 提供，缺失、权限不足或上游不完整按来源失败处理；日志必须能区分真实在线采集、显式离线与来源失败。
