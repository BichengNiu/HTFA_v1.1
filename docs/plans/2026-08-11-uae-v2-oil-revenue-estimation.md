# UAE V2 石油收入估算方案

## 目标

使用现有原油价格和阿联酋原油产量，估算月度石油收入，接入“石油 → 财政 → 非油经济”传导链。

## 估算公式

```text
月度石油收入（亿美元）
= 月均原油价格（美元/桶）
× 月均原油产量（桶/天）
× 当月天数
÷ 100,000,000
```

## 数据口径

- 原油价格：优先使用穆尔班现货月均价。
- 穆尔班价格缺失时，依次使用迪拜现货、布伦特现货。
- 原油产量：使用现有 OPEC 阿联酋月度原油产量，单位为桶/天。
- 月均油价只使用该自然月内的有效观测，不跨月填充。
- 收入月份必须同时具备价格和产量；不使用旧产量外推未来月份。

## 输出指标

1. 月度石油收入：亿美元。
2. 环比变化：与上月相比的百分比变化。
3. 同比变化：与上年同月相比的百分比变化。
4. 本年度累计收入：本年度截至最新有效月份的月度收入之和，单位为亿美元。

## 页面展示

- 指标卡：最新月石油收入、本年度累计收入、环比、同比。
- 收入图：月度石油收入柱状图，以及总收入同比、价格拉动率和产量拉动率三条曲线；左轴为亿美元，右轴为百分比。
- 辅助说明：显示采用的价格序列、价格和产量截止日期。

## 口径说明

该指标是按市场价格估算的原油收入，不扣除生产成本、国内炼化用量、运输费用、税费或其他分成，因此不等同于政府实际财政收入。页面统一标注为“估算石油收入”。

## 验收条件

- 价格、产量和日期单位转换正确。
- 大月、小月和闰年天数计算正确。
- 缺少价格或产量的月份不生成收入。
- 图表和指标卡使用同一套月度结果。
- 页面明确展示“估算值”及所用价格基准。
