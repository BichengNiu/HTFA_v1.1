# UAE行业增长集中度图重构设计

## 目标

将解释不稳定的三个子图合并为一张“行业增长的方向与集中度”气泡图，使增长、收缩、集中、分散和变动强度在同一视觉空间内可辨认。

## 指标设计

1. **贡献平衡指数**：`Σcᵢ/Σ|cᵢ|×100`，范围－100到100；负值为拖累主导，0为完全抵消，正值为拉动主导。
2. **绝对贡献HHI**：`Σ(|cᵢ|/Σ|cᵢ|)²`，正负贡献统一进入分母，增长期和收缩期含义一致。
3. **标准化绝对贡献集中度**：固定16行业使用 `(HHI－1/16)/(1－1/16)×100` 转换；0为等额变动，100为单一行业主导。
4. **总变动强度**：`Σ|cᵢ|`，单位为百分点，用于气泡面积。
5. 行业贡献缺失或全部为0时整季为空；悬浮报告非油GDP同比和最大正负贡献行业。

## 图表设计

使用单张二维气泡图：横轴为贡献平衡指数，纵轴为标准化绝对贡献集中度，气泡面积为总变动强度。净增长期使用实心圆，净收缩期使用空心圆；横轴0线作为增长/收缩分界。沿用行业量价四象限图的Plotly `frames + layout.sliders + updatemenus` 机制：每个季度frame显示截至该季的历史点，并用深色描边突出当前季度，支持图内拖动、从头播放和暂停。

横轴始终固定为－100到100。纵轴理论范围为0—100，但显示上限按完整样本最大值留出20%余量后向上取整到5的倍数，最低20、最高100；所有frame共用这一固定范围，避免观测贴近横轴且不产生逐帧缩放错觉。图内同时标出显示范围和理论范围。

## 兼容与验证

- 不保留旧CR3、正向贡献HHI、正向贡献行业数、行业增速标准差和负向拖累占比兼容字段。
- 更新计算、服务方法说明、指标字典和图表测试。
- 合成测试覆盖正负贡献并存、全部正贡献、全部负贡献和50%净增长分界。
- 运行行业增长、服务和渲染测试，并执行UAE相关完整回归。

## 图下指标说明

- 在“行业增长集中度”三联图正下方增加默认折叠的“指标算法与解读”expander。
- 内容说明行业贡献、贡献平衡指数、标准化绝对贡献集中度、总变动强度、四个位置和空值边界。
- 每项只保留公式、数值方向和关键边界；不显示当前季度数值，不依赖具体上传工作簿。
- 该expander只属于行业增长集中度图，不加入其他图或面板底部的通用证据说明。

行业分析进一步为以下三张图增加同名的默认折叠expander：

- “GDP部门拉动与石油产量同比”：说明油/非油拉动的同比贡献公式、加总关系，以及石油产量同比不能与贡献柱相加。
- “非油实际GDP同比及行业拉动”：说明行业拉动公式、前5行业固定选择与其他11行业合并规则，以及柱形加总关系。
- “行业增长广度与持续性”：说明16行业不加权正增长比例、连续四季度正增长比例、50%/80%参考线及两线差距含义。

四个图下说明均使用“指标算法与解读”标题，内容集中定义并由同一渲染函数按图表键选择。

## 行业分析Tab叙事顺序

行业分析遵循“增长结果 → 增长来源 → 增长质量 → 当前动能 → 量价性质”的问题链，同时实现从总体到行业、从长期趋势到短期诊断：

1. GDP部门拉动与石油产量同比；
2. 非油实际GDP同比及行业拉动；
3. 行业扩张广度指数；
4. 行业增长集中度；
5. 行业增长持续性与状态矩阵；
6. 行业量价四象限图。

在第一、第三和第五张图前分别显示“长期趋势：总量与增长来源”“中长期结构：行业增长质量”“短期动能：行业状态与量价表现”三个三级标题。渲染器必须按显式标题元组排序，而不是沿用服务层字典插入顺序。

## 行业增长广度图简化

- 图表标题改为“行业增长广度与持续性”。
- 仅展示不加权口径，删除加权/不加权切换按钮和加权轨迹。
- 四条线精简为“正增长行业比例”和“连续四季度正增长行业比例”两条线。
- “高于历史均值”和“较上季度加快”由后续行业状态矩阵承担，不在广度图重复展示。
- 保留50%和80%参考线；后台加权派生结果暂时保留，不改变计算结果合同。
